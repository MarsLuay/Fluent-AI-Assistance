## Improvement

Marginal: could discover the local FluentControl WCF/SiLA endpoint instead of hardcoding `TECAN_FLUENT_HOST` / `TECAN_FLUENT_PORT` (50052), but WCF workspace APIs are version-sensitive; a native API V2 COM provider should not depend on this.

## Implementation

- `fluent_pipeline/api_v2/legacy_sila.py` — `resolve_legacy_service_endpoint()` documents env-configured endpoints and **does not** call `GenerateServiceEndpoint()`.
- `fluent_pipeline/api_v2/context_enrichment.py` — attaches `legacy_service_endpoint` metadata to runtime-report JSON for observability.

## Usage

Keep using `TECAN_FLUENT_HOST` / `TECAN_FLUENT_PORT`. Treat `GenerateServiceEndpoint()` as design-only for legacy SiLA bootstrap notes, not a runtime dependency for API V2 providers.
